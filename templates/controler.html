Remote Desktop Control

A PowerShell script that turns your Windows laptop into a simple remote desktop server, controlled from any phone/browser on the same network.

Features

  • View live screen (auto-refreshes every 2s)
  • Left click and right click
  • Type text (sent with a delay between characters)

Requirements

  • Windows with PowerShell
  • Phone/device on the same Wi-Fi network

Setup

  • Download bloothout.ps1.
  • Right-click the file and select "Run with PowerShell" (or run from a terminal).
  • If prompted about execution policy: powershell -ExecutionPolicy Bypass -File bloothout.ps1
  • Note the IP/URL printed in the console.
  • Open that URL in your phone's browser.

Usage

  • Tap the screen image to click.
  • Toggle "Right-Click" before tapping to right-click instead.
  • Type in the text box and press Enter to send text to the laptop.
